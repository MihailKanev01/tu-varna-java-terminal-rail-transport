# Rail Transport Model

A Java study project that models a railway network and its rolling stock through object-oriented domain classes.

## Overview

The codebase represents railway concepts such as stations, towns, coordinates, routes, trains, locomotives and wagons. It includes different locomotive types (steam, diesel and electric) as well as passenger and freight wagons.

## Concepts Demonstrated

- Object-oriented modelling and class relationships
- Inheritance and specialised vehicle types
- Railway stations, routes and map-related data
- Separation of domain concepts into focused Java classes

## Technology

- **Language:** Java
- **Project type:** Educational domain-model exercise
- **Source:** `src/rail_transport/`

## Getting Started

The repository currently exposes the domain classes listed above; a runnable application entry point is not evident in the source tree.

1. Clone the repository:
   ```bash
   git clone https://github.com/MihailKanev01/tu-varna-java-terminal-rail-transport.git
   cd tu-varna-java-terminal-rail-transport
   ```
2. Open the project in IntelliJ IDEA or another Java IDE.
3. Compile the Java files and explore the model classes.

## Project Status

An educational project focused on modelling railway transport concepts. The README describes the checked source structure and does not imply a production-ready railway system.
